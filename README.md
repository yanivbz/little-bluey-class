# Puppy Teacher · המורה של אופיר

אפליקציית לימוד פשוטה לכיתה א' – הכתבה וחשבון עם מורה כלבלב. אופיר כותבת במחברת אמיתית; המסך מציג, מקריא ומראה את התשובה לבדיקה.

🌐 https://yanivbz.github.io/puppy-teacher/

## יכולות
- **הכתבה** – שלושה מצבים: רואים ומעתיקים · מסתכלים וזוכרים (המילה נעלמת אחרי כמה שניות) · שומעים וכותבים (הקראה בעברית, "המשך" חושף את המילה המנוקדת). בסוף – חזרה על הרשימה.
- **חשבון** – חיבור עד 10/20/29, "מה חסר?", חיסור עד 20. אופיר בוחרת תשובה מתוך 4 כפתורים; עזרה במסגרות עשר.
- **מילים לתרגול** – אחרי חשיפת מילה מסמנים ✔️/✖️; מילים קשות חוזרות ראשונות (יוצאות אחרי 2 הצלחות ברצף).
- **החדר שלי** – מרוויחים מטבעות (תשובה נכונה, מילה נכונה, סיום סבב +3) וקונים פריטים לקישוט החדר; גוררים למקום, לחיצה מחזירה למגש.
- **הקלטת קול** (לא חובה) – באזור ההורים 🎙️ ליד כל מילה; בהכתבה מושמעת ההקלטה במקום הקול הממוחשב.
- כוכבים, נקודות התקדמות ועידוד מהמורה (גם בקול).

## אזור הורים (⚙️ במסך הבית)
1. כתבו שם לרשימה ומילה בכל שורה. סרגל הניקוד מוסיף סימן ניקוד במקום הסמן. הדבקת טקסט מנוקד נשמרת כמו שהיא.
2. **✨ ניקוד אוטומטי** – שולח את המילים לשירות Dicta Nakdan ומציג הצעה לעריכה ואישור.
3. **📷 צילום דף** – התמונה נשמרת עם הרשימה, וזיהוי טקסט (Tesseract.js) מציע רשימת מילים לאישור.
4. **💾 שמירה**. אפשר לערוך ✏️ / למחוק 🗑️ / לצפות בתמונה 🖼️, ולקבוע את שניות ההצגה במצב זיכרון.

הנתונים נשמרים בדפדפן של המכשיר בלבד (localStorage).

## מבנה קבצים
```
index.html     מסכים
style.css      עיצוב
app.js         לוגיקה
words.js       רשימת מילים התחלתית
manifest.json  התקנה למסך הבית
assets/        ציורי המורה (wave / pencil / think / cheer)
screenshots/   צילומי מסך
```

## פרסום ב-GitHub Pages
1. העלו את הקבצים לשורש ענף `main`.
2. Settings → Pages → Deploy from a branch → `main` / `(root)`.
3. אחרי דקה האתר זמין.

📲 **התקנה כאפליקציה:** בכפתור "התקנת האפליקציה" במסך הבית (אנדרואיד/כרום), או באייפון: שיתוף ⬆️ ← "הוסף למסך הבית".
