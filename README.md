# Puppy Teacher · המורה של אופיר

אפליקציית לימוד סטטית (HTML/CSS/JS, בלי build) לכיתה א'. אופיר כותבת במחברת אמיתית; המסך מציג, מקריא ומראה את התשובה לבדיקה.
אתר: https://yanivbz.github.io/puppy-teacher/

## מבנה
```
index.html     מסכים: בית, בחירת מצב הכתבה, הכתבה, חשבון, אזור הורים
style.css      עיצוב (קרם, אפרסק/מנטה/לבנדר, RTL)
app.js         לוגיקה
words.js       רשימת מילים התחלתית (עם ניקוד)
manifest.json  התקנה למסך הבית
assets/        ציורי המורה הכלבלב (wave/pencil/think/cheer)
```
## יכולות
- הכתבה: רואים ומעתיקים / מסתכלים וזוכרים (שניות מוגדרות) / שומעים וכותבים (הקראה עברית, "המשך" חושף את המילה). חזרה על הרשימה בסוף.
- חשבון: חיבור עד 10/20/29, מה חסר, חיסור עד 20; בדיקה → המשך; עזרת מסגרות עשר.
- אזור הורים (⚙️): רשימות שבועיות, סרגל ניקוד, ניקוד אוטומטי (Dicta Nakdan), צילום דף נשמר עם הרשימה + זיהוי טקסט (Tesseract.js) לאישור.
- כוכבים והגדרות נשמרים ב-localStorage.

## פרסום ב-GitHub Pages
1. דחפו את הקבצים לשורש ענף `main` במאגר.
2. Settings → Pages → Deploy from a branch → `main` / `(root)`.
3. אחרי דקה: `https://<user>.github.io/<repo>/`. בטאבלט: "הוסף למסך הבית".
