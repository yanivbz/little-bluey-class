# Little Bluey Class – הכיתה של אופיר

אפליקציית לימוד סטטית (HTML/CSS/JS, בלי build) לכיתה א'. הילדה כותבת במחברת אמיתית – המסך רק מציג/מקריא ובודק.

## מבנה קבצים
```
index.html   – מבנה המסכים
style.css    – עיצוב (RTL, כפתורים גדולים)
app.js       – לוגיקה: ניתוב, הכתבה (3 מצבים), חשבון, אזור הורים, דמויות SVG מקוריות
words.js     – רשימת מילים התחלתית (אפשר לערוך)
screenshots/ – צילומי מסך
```
## מצבים
- 👀 הצגה מלאה – מילה עם ניקוד, קודמת/הבאה.
- ⚡ זיכרון – מילה מוצגת X שניות (הגדרה באזור הורים, ברירת מחדל 3) ואז נעלמת.
- 🔊 הכתבה – הקראה בקול (he-IL), "המשך" חושף את המילה לבדיקה.
- ➕ חשבון – חיבור עד 10/20/29, מחובר חסר, חיסור עד 20; "בדיקה" חושף תשובה; עזרה ויזואלית (מסגרות עשר).
- ⚙️ אזור הורים – הוספה/עריכה/מחיקה של רשימות (נשמר ב-localStorage), העלאת תמונה (OCR בקרוב), זמן הצגה.

## פרסום ב-GitHub Pages
1. צרו מאגר חדש ב-GitHub (למשל `ofir-app`) והעלו את כל הקבצים לשורש המאגר.
2. Settings → Pages → Source: `Deploy from a branch`, Branch: `main`, תיקייה `/ (root)` → Save.
3. אחרי דקה-שתיים האתר זמין ב-`https://<user>.github.io/ofir-app/`. בטאבלט: "הוסף למסך הבית".

## הערות
- הקראה תלויה בקול עברי במכשיר (iOS/Android/Chrome בדרך כלל כוללים). בלי קול עברי – המילה מוצגת במקום.
- הנתונים נשמרים בדפדפן המקומי בלבד.
- הדמויות הן ציורי SVG מקוריים בהשראת כלבי היילר כחול/כתום, לא תמונות רשמיות.
